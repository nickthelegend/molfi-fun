# 100 ideas, ranked

Generated by reading the repo, not by brainstorming in the abstract. Nothing here already
exists — every "port X" and "fix Y" that was already done is excluded.

## The one thing that decides this

molfi's contract is deployed on Sepolia with nine funded markets, and **not one of them can
ever settle**, because Pragma stopped publishing to Sepolia months ago. Mainnet has a live
oracle and no deployment, because that costs money nobody has spent.

So the demo today can show a contract, and cannot show the thing the contract is *for*. A
judge watching a prediction market that has never resolved a prediction is watching a
screenshot. Almost every high-ranked idea below exists to fix that, and most of the rest are
worth far less until it is fixed.

## What that ranking means

Ideas 1 through 10 are one feature wearing ten hats: **make the market actually run.** They
are built first and together, because none of them is worth anything alone.

Ideas 97 through 100 are on the list to be explicitly rejected. A sub-account flow cannot be
built against a Wallet API route that does not exist. An order book contradicts the reason
this project is private at all. A token would make a privacy submission look like a
fundraise. And a mainnet deploy is the user's money.
